# 快速验证指南: 修复 RPG 游戏颜色错位

**日期**: 2026-06-06

## 前置条件

- Node.js 已安装，`npm install` 已完成
- `roms/` 目录下有至少一款 RPG 类 .nes ROM（如"吞食天地"、"勇者斗恶龙"等）
- 至少一款非 RPG 类 ROM 用于回归对比（如"超级玛莉"）

## 验证步骤

### 1. 启动开发服务器

```bash
npm run dev
```

### 2. RPG 游戏颜色验证

1. 打开浏览器访问列表页（默认 `http://localhost:5173`）
2. 点击一款 RPG 游戏进入详情浮层
3. 点击"开始游戏"进入模拟器页面
4. 投币 → 开始，进入游戏画面
5. 观察画面颜色：
   - **红色区域**（角色皮肤、红色 UI 文字、红色血条等）应显示为正红色，不再偏蓝紫
   - **蓝色区域**（天空、水域、蓝色 UI、蓝色敌人等）应显示为正蓝色，不再偏橙红
   - **绿色区域**（草地、树木等）颜色应无明显变化
   - **白色/黑色**（文字、边框）应无明显变化

### 3. 非 RPG 游戏回归验证

1. 返回列表页
2. 启动"超级玛莉"或任意非 RPG 游戏
3. 确认：
   - 马力欧的红色帽子/衣服为正红色（原来偏蓝）
   - 天空蓝色为正常天蓝（原来偏红）
   - 绿色管道/草地颜色正常

### 4. E2E 测试

```bash
npx playwright test tests/e2e/game.spec.js
```

确认所有测试通过，无新增失败用例。

### 5. 性能验证

在游戏运行中打开浏览器 DevTools Performance 面板，录制 5 秒，确认帧率稳定在 60 fps。

## 预期结果

- RPG 游戏画面红蓝通道正确，颜色与参考截图一致
- 非 RPG 游戏画面颜色正确，无回归
- 60 fps 渲染稳定
- E2E 测试全部通过
